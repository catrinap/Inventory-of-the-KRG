# Автоматизация «Отчёт по ТГ» с учётом КРГ

Streamlit-приложение, которое по загруженному Excel-файлу с листами
«Данные КРГ» и «Отчет по ТГ» само строит третий лист «Готовый отчет по ТГ»:
делает сводную по Товарной группе (Дельта, СуммаРозница, СуммаПриход) и
подставляет её в отчёт, прибавляя дельту КРГ к фактическим остаткам —
формулами, ничего не удаляя из исходных формул отчёта.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Откроется браузер на `http://localhost:8501`. Загружаете .xlsx → жмёте
«Собрать «Готовый отчёт по ТГ»» → скачиваете готовый файл.

## Публикация в интернет (бесплатно)

1. Залейте `streamlit_app.py`, `report_builder.py`, `requirements.txt` в
   репозиторий на GitHub.
2. Зайдите на https://streamlit.io/cloud, подключите репозиторий, укажите
   `streamlit_app.py` как главный файл — приложение опубликуется по
   отдельной ссылке, доступной коллегам.

Альтернатива — Render, Railway или любой сервер с Python (uvicorn/gunicorn
для streamlit не нужен, просто `streamlit run` за reverse-proxy).

## Файлы

- `streamlit_app.py` — интерфейс (загрузка файла, кнопка, скачивание).
- `report_builder.py` — вся логика: сводная, клонирование листа, формулы,
  таблица Excel, подсветка изменённых ячеек.

## Если структура файла немного отличается

`report_builder.py` ищет нужные столбцы по названиям заголовков (с
частичным совпадением), а не по жёстким буквам столбцов — так что
приложение переживёт небольшие изменения порядка столбцов. Если названия
заголовков совсем другие, при ошибке приложение подскажет, какого столбца
не хватает.
